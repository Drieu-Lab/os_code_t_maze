# ADR 0138: The forced probe block honours the session's anti-bias run caps

- **Status:** Accepted
- **Date:** 2026-08-28
- **Author / Agent:** Agent (Cursor) on behalf of Celine
- **Affects:** `host/tmaze/core/phase3/probe_blocks.py`
  (`ProbeBlockController.max_same_run` / `max_alt_run` fields, `_make_plan`),
  `host/tmaze/core/phase3/trial_sequence.py` (threads
  `sequence.max_same_run` / `max_alt_run` into the controller),
  `host/tests/test_phase3_probe_blocks.py`
- **Supersedes / Superseded by:** builds on ADR-0115 / ADR-0134 (why probes exist
  and how they trigger); refines the block-generation detail only.

## Context

The main choice schedule is a counterbalanced L/R spine generated by
`generate_balanced`, which honours two operator-set anti-bias caps from
`sequence` in `phase3.json`: `max_same_run` (longest allowed single-side run) and
`max_alt_run` (longest allowed strict L/R/L/R alternation), 0 = disabled. These
stop the rat exploiting a long predictable run or a metronome pattern.

The forced probe block (ADR-0115/0134) reuses the SAME `generate_balanced` for its
internal 5/5 counterbalancing, but was calling it with `max_run=0, max_alt=0` -
so a probe block ignored those caps. With the caps set, that let a probe hand the
animal a longer same-side run (e.g. up to `LLLLL`) than any other part of the
session allows - a within-probe confound the caps exist to prevent.

## Decision

Thread the session's `max_same_run` / `max_alt_run` into the probe controller and
pass them to `generate_balanced` when building the block.

- `ProbeBlockController` gains `max_same_run` / `max_alt_run` fields (default 0,
  like `seed`); `TrialSequence` sets them from `self.cfg.max_same_run` /
  `max_alt_run` when it constructs the controller.
- `_make_plan` calls `generate_balanced(n, n, self.max_same_run, rng,
  max_alt=self.max_alt_run)`. The whole block is one balancing unit
  (`block == n`), so the cap is enforced **within** the block; it does not consider
  the trigger trial before it or the trials after the block.
- No new config keys: the probe deliberately inherits the session's caps rather
  than getting its own, so a probe block is never freer than the main schedule.
  The values are already recorded in the CSV header (the `sequence` params), so no
  extra logging is needed.

## Alternatives considered

- **Give probes their own `probe_blocks.max_same_run` / `max_alt_run`.** Rejected:
  more knobs, and the scientific intent is simply "a probe should be no more
  biased than the rest of the session". Inheriting is the least-surprise default.
- **Leave the caps off for probes (status quo).** Rejected: a 10-trial block with
  no run cap can produce e.g. `RRRRR...` streaks that the caps forbid everywhere
  else, confounding the latent-knowledge read-out.
- **Chain the cap across the trigger trial / block boundary.** Rejected as
  over-engineering: the block is inserted on top of the spine and the trigger side
  is set by the animal's choice, so treating the block as its own balanced unit is
  the clean, testable scope.

## Consequences

- With `max_same_run` / `max_alt_run` set, the probe block re-rolls (up to
  `generate_balanced`'s attempt cap) until it satisfies them, then falls back to
  the last shuffle - same best-effort contract as the main schedule.
- The within-block pattern stays seed-deterministic *given the caps*; changing a
  cap changes the generated pattern for a fixed seed (expected).
- **In the current `phase3.json` both caps are 0**, so this is a no-op until the
  operator raises them; it removes a latent confound the moment they do.

## Evidence / links

- `host/tests/test_phase3_probe_blocks.py`: `test_block_honors_max_same_run` /
  `test_block_honors_max_alt_run` (block obeys the cap across seeds, still 5/5),
  `test_no_cap_leaves_block_unconstrained` (with caps 0 a long run can appear -
  proving the cap is real), and `test_block_honors_session_max_same_run` (the cap
  threads through `TrialSequence`). Full probe suite green (32 tests).
- Builds on ADR-0115 / ADR-0134 (probe blocks), ADR-0047 (counterbalanced spine +
